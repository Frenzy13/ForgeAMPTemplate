How to use this repo

  1. Replace the placeholder values in server.js and public/index.html with your repo and GitHub Pages URL.
  2. Use the chooser to pick the preferred Tailscale address and ignore Radmin entries.
  3. Push this folder to a GitHub repository.
  4. Enable GitHub Pages in the repo settings.
  5. Paste the published GitHub Pages URL into AMP.
